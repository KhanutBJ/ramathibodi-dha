## วิธีใช้ Notebook

1. คลิก **เปิด Notebook** เพื่อดูเนื้อหาและโค้ดทั้งหมด
2. ดาวน์โหลดไฟล์ `.ipynb` หรือเปิดบน Google Colab
3. รันทีละเซลล์ แก้ค่าและทดลองด้วยตัวเอง
4. นำสิ่งที่เรียนไปต่อยอดใน Capstone Project ของคุณ

```{tip} เรียนคู่กับหลักสูตร
แต่ละ Notebook เชื่อมกับโมดูลในหลักสูตร แนะนำให้อ่านเนื้อหาในส่วน [หลักสูตร](../curriculum/overview.md) ควบคู่ไปด้วย
```
