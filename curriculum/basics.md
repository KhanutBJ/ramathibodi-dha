# ทักษะพื้นฐาน (Basics)

ทักษะพื้นฐานที่นักพัฒนาด้าน Digital Health ทุกคนควรมี ก่อนเข้าสู่โมดูลขั้นสูง

---

## 1. Vibe Coding / No-Code

การพัฒนาซอฟต์แวร์ในยุคที่ AI ช่วยเขียนโค้ด — เรียนรู้วิธีใช้ AI Coding Assistant อย่าง GitHub Copilot, Cursor และ Claude เพื่อเพิ่มประสิทธิภาพการทำงาน รวมถึงเครื่องมือ No-Code / Low-Code สำหรับการสร้าง Prototype อย่างรวดเร็ว

**สิ่งที่จะเรียน:**
- การใช้ AI Assistant ช่วยเขียนโค้ด Python
- Prompt Engineering สำหรับ Coding
- เครื่องมือ No-Code: Bubble, Glide, AppSheet
- การสร้าง Prototype อย่างรวดเร็วด้วย Streamlit / Gradio

---

## 2. Git และการควบคุมเวอร์ชัน

การทำงานร่วมกันในทีมพัฒนาซอฟต์แวร์ — ทักษะที่ขาดไม่ได้สำหรับทุกโปรเจกต์

**สิ่งที่จะเรียน:**
- Git พื้นฐาน: init, commit, push, pull, branch, merge
- GitHub / GitLab: Pull Request, Code Review
- Git Flow สำหรับทีม
- การจัดการ Conflict

---

## 3. Library และ Documentation

ทักษะการใช้งานไลบรารี Python สำหรับ Data Science และ AI

**ไลบรารีที่ครอบคลุม:**
- **Data**: pandas, numpy, polars
- **Visualization**: matplotlib, seaborn, plotly
- **ML**: scikit-learn, xgboost
- **Deep Learning**: PyTorch, TensorFlow (เบื้องต้น)
- **Healthcare**: pydicom, mne, nibabel

**การอ่าน Documentation:**
- วิธีค้นหาและอ่าน API Reference
- การดู Source Code และ GitHub Issues
- Stack Overflow และ Community Resources

---

## 4. API

การเชื่อมต่อระบบต่าง ๆ ผ่าน API — ทักษะสำคัญในการสร้างระบบ Digital Health

**สิ่งที่จะเรียน:**
- REST API: GET, POST, PUT, DELETE
- Authentication: API Key, OAuth 2.0, JWT
- การเชื่อมต่อ FHIR API
- การใช้งาน OpenAI / Claude API
- FastAPI: สร้าง API ด้วย Python

---

## 5. Cloud Computing

พื้นฐาน Cloud สำหรับการ Deploy ระบบ Digital Health

**สิ่งที่จะเรียน:**
- Cloud Providers: AWS, GCP, Azure (ภาพรวม)
- Cloud Run: Deploy Containerized App
- Cloud Storage: เก็บข้อมูลทางการแพทย์อย่างปลอดภัย
- IAM: การจัดการสิทธิ์การเข้าถึง
- ความปลอดภัยของข้อมูลบน Cloud (PDPA)

---

```{tip} แนะนำสำหรับผู้เริ่มต้น
เริ่มจาก Git → Python Library → API → Cloud ตามลำดับ หากมีพื้นฐาน Python อยู่แล้ว สามารถข้ามไปเริ่มที่ API ได้เลย
```
